# Список задач (To-Do List)

Простое приложение для управления списком задач на Python + tkinter/ttk.

## Возможности

- Добавление задач через поле ввода
- Удаление задач из списка
- Отдельная вкладка с отметкой выполненных задач (чекбоксы)
- Хранение задач в файле `todo.json`

## Требования

- Python 3.13+ (использует стандартную библиотеку tkinter, дополнительных пакетов не требуется)

## Запуск

### Через bat-файл (без окна консоли)

Запустите `run.bat`

### Вручную

```
python main.py
```

### Через vbs-файл (совсем без окна консоли)

Запустите `run_hidden.vbs`

## Структура проекта

- `main.py` — основной код приложения
- `todo.json` — файл с сохранёнными задачами (создаётся автоматически при первом запуске)
- `run.bat` / `run_hidden.vbs` — запуск приложения без консольного окна
- `icon.ico` / `icon.png` — иконка приложения
